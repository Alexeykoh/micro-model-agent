# Спеки версии 0.25.2

Багфикс-волна «агент не получает честной обратной связи» (2026-11-10). Две
половины одной беды.

Первая — «агент сдаётся вместо работы»: модель на Windows-машине с недоступным
`cmd.exe` получала вводящую в заблуждение ошибку от `bash`, харнесс усилием
`exec.honest_stop` приказывал «не пробуй ничего другого», критик молчал
(fail-open + слепые улики), а финальный аудит не запускался на форс-финале.

Вторая — «харнесс врёт о сделанном»: на живом прогоне (MMA 0.25.1,
`llama.cpp` → `qwen3.8-27b`, 4 сессии, ~68 мин) план уходил в `done` при
отсутствующих файлах, финальный аудит печатал «[✓] Задача выполнена» в одном
сообщении с «проверка не пройдена» и валил успешный прогон `exit 1`, LSP
pre-write блокировал корректную запись ложным `implicit any`.

## Порядок внутри волны

Задачи **A и C** из второй спеки — предпосылка для S5 и S6:

- S5 строит улики критика на `isUnconfirmed` — пока A и C-причина-2 живы, этот
  источник состояния плана врёт;
- S6 включает `auditGate` на форс-финале — пока C жив, он умножает число мест,
  где успешная работа заканчивается `exit 1`.

То есть S5 и S6 — после A и C. B, D, E с S1…S6 не пересекаются.
