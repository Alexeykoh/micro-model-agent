# Webui DLP: тип секрета и маскированный отпечаток

**Дата:** 2026-10-22 · **Ветка:** `fix/harness-audit-w1w2-loop` · **Статус:** принято

## 1. Задача

Попап DLP показывает агрегат «Секреты 3» без единой подсказки, что именно было
заменено. Оператор не может понять, заблокирован ли нужный ему ключ или случайный
фрагмент. Нужно показать **тип** находки и **маскированный отпечаток** значения,
не раскрывая оригинал.

Это расширение контракта `2026-10-20-webui-dlp-indicator-design.md` §2.2:
раздел «вне рамок» (список конкретных фрагментов) снимается частично — только
для маскированных отпечатков секретов.

## 2. Что показываем

- Тип: `API-ключ` (`secret:key`), `Bearer-токен` (`secret:bearer`), `JWT`
  (`secret:jwt`), `Токен известного формата` (`secret:prefix`).
- Отпечаток: первые 4 и последние 2 символа значения через `…`:
  `sk-p…a2`, `ghp_…9f`, `AKIA…7Q`. Значения короче 8 символов отпечатка не имеют.
- Счётчик по типу (та же арифметика, что у `stats.secret`: max за вызов, сумма
  по видам).

Оригиналы и token id по-прежнему не выходят за пределы guard'а.

## 3. Контракт данных

`EgressTokenRef` получает необязательное поле:

```ts
preview?: string; // маскированный отпечаток; только для dataClass === "secret"
```

`EgressTurnSummary` получает необязательное поле:

```ts
secrets?: Array<{ kind: string; count: number; previews: string[] }>;
```

- `kind` — публичный вид (`key`, `bearer`, `jwt`, `prefix`, либо исходный вид,
  если он уже публичный).
- `previews` — уникальные отпечатки, не более 6 на вид, сортировка стабильна.
- Поле отсутствует, если секретов не было (чистый ход не меняет форму агрегата).
- Внутренние id паттернов (`secret:key`, `secret:0`) наружу не выходят;
  неизвестный `secret:*` схлопывается в `other`.

## 4. Поток

1. `detectSecrets` находит диапазон значения.
2. `projectText` строит отпечаток `secretPreview(value)` и кладёт в
   `EgressTokenRef.preview`.
3. `recordEgressTurn` складывает отпечатки в бакет; `maskedMax` даёт счётчики.
4. `summaryOf` собирает `secrets[]`.
5. Webui `feed/egress.ts` рисует под строкой «Секреты» вложенные строки
   «тип · отпечатки · счётчик».

## 5. Инварианты

- **INV-DLP-1** не нарушается: оригинала и token id нет ни в SSE, ни в истории,
  ни в `session.jsonl`. Отпечаток — производное, не восстанавливающее значение.
- **INV-DLP-6.** Отпечаток не содержит значения целиком и не длиннее 8 видимых
  символов (4 + 2 + разделитель).
- **INV-DLP-7.** Отпечаток не должен сам матчиться детектором секретов (иначе E2
  перепишет его в `[SECRET]` в истории). Проверяется тестом.
- **INV-DLP-8.** Число отпечатков на вид ограничено (6), чтобы агрегат не рос.
