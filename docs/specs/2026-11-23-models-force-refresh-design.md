# Спека: явное обновление списка моделей

Дата: 2026-11-23 · Ветка: `fix/models-refresh-button` · Связано:
`2026-11-17-provider-model-invariant-design` (честные состояния списка)

## Проблема

Кнопка «обновить список» в меню модели композера дёргала `GET /api/models`, а тот
читал кэш: `knownModelsRefresh()` вызывался только после ошибки (`error: true`).
Пока список готов, повторный GET возвращал те же id — провайдер не опрашивался,
внешне кнопка ничего не делала (добавил модель в llama.cpp — в меню её нет).

## Контракт

`GET /api/models?refresh=1` — явный запрос на переопрос активного провайдера.

- Если `knownModelsRefresh` подключён, сервер запускает его в фоне и считает
  запрос принятым (`200`). Повторный `listModels()` и публикация SSE `models`
  остаются в ответственности хука (`installModelSurface.refreshAndPublish`).
- Ответ содержит **текущий** снимок с честными `loading`/`error`. Готовый список
  не подменяется на «загрузка моделей…» во время фонового refresh (INV-P1,
  баг 5ff9911b). Клиент перерисовывается по SSE `models`.
- Без флага — старое поведение: читаем кэш, фонового опроса нет. Повтор после
  `error: true` по-прежнему запускается обычным GET.
- `?provider=<name>` (страница экспертов) флаг не затрагивает: ленивый
  per-provider кеш живёт по своим правилам.

Тот же флаг принимает host wire `GET /v1/host/models?refresh=1`; daemon-адаптер
пробрасывает его через `Host.listModels(provider?, refresh?)`. Оба параметра
аддитивные: старые клиенты и старые серверы продолжают работать.

## Клиент

`requestModelsRefresh()` в `settings/models-load.ts` — отдельный вызов, не
часть `loadModels()` single-flight: фоновый ре-read из SSE не должен съедать
явное нажатие. При принятом запросе показывается тост «обновляем список…»,
при сетевом отказе — «не удалось обновить список». Фактический список
перерисовывается только по свежим данным.

## Проверки

- `tests/webui-models-per-provider.test.ts` — `?refresh=1` запускает рефреш
  готового списка и не прячет его; обычный GET рефреш не запускает.
- `tests/models-load.test.ts` — кнопка ходит на `/api/models?refresh=1`.
- `bun run quality` — гейты контракта/архитектуры и размеров файлов.
