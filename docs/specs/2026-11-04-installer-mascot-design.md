# Маскот и прогресс в терминале установщика — дизайн

Дата: 2026-11-04. Ветка: `feat/legacy-npm-adoption`.

## Проблема

Сейчас установщик печатает плоские строки `mma: ...`, а загрузка идёт через
`curl --progress-bar`: без процентов и размеров, без цвета, без ощущения
продукта. Пользователь встречает MMA впервые именно здесь.

## Цель

Сделать первый экран установки узнаваемым и живым, не ломая надёжность и
машинную читаемость:

- маскот MMART (скруглённый квадрат с двумя глазами) в ASCII;
- акцентный цвет палитры лендинга (`#c4a8ec`), зелёный успех, красная ошибка;
- собственная полоса загрузки: 26 ячеек, проценты и MB;
- состояния: `idle` → загрузка → `happy`/`sad`.

## Ограничения

- `scripts/install.ps1` обязан остаться **ASCII-only**: Windows PowerShell 5.1
  читает файл без BOM как ANSI. Гейт — `tests/install-retry.test.ts`.
- Скрипты запускаются через `irm | iex` и `curl | bash`: нельзя зависеть от
  внешних файлов, шрифтов, Unicode-глифов и TTY.
- Анимация не должна влиять на результат установки и на время в неинтерактивном
  режиме.

## Решение

### Баннер

```
  +-------------+  MMA installer
  | []      []  |  GitHub Releases - win-x64
  +-------------+  home: C:\Users\me\.mma
```

Строка глаз — состояния: `[]` покой, `--` моргание, `^` успех, `x` ошибка.
Печатается до preflight (и в dry-run), чтобы план было видно сразу.

### Цвет

Включается только при TTY и отсутствии `NO_COLOR`/`CI`/`TERM=dumb`:

| Роль              | ANSI 256   |
| ----------------- | ---------- |
| акцент / рамка    | `38;5;183` |
| успех             | `38;5;150` |
| ошибка            | `38;5;203` |
| размеры / подписи | `38;5;245` |

`install.ps1` дополнительно требует `$Host.UI.SupportsVirtualTerminal` или
`WT_SESSION`/`TERM`; в остальных случаях — plain-текст без escape-кодов.

### Прогресс загрузки

- **`install.sh`** рисует свою полосу: `curl -sS` в фоне и опрос размера файла —
  `\r  [##########------------]  42%  6.7/16.1 MB  download`. `wget`-ветка
  получает ту же полосу. Неинтерактивно — тихий curl без полосы.
- **`install.ps1`** оставляет нативную `--progress-bar` при TTY (свой бар через
  `Start-Process` ломал резюм/код возврата curl в PowerShell 5.1) и `-sS` в
  неинтерактивном режиме.
- По завершении: полная полоса `100% ready` (sh) / баннер `happy`. При мгновенной
  загрузке (тестовый артефакт) полоса может не успеть появиться — это допустимо.

### Успех и ошибка

Успех: `happy`-маскот + `installed MMA <version>`. Ошибка: `sad`-маскот перед
`Die`. На неинтерактивном выводе — только строки, без лиц (кроме финальной
маски, если включён TTY).

## Проверки

- `install.ps1` ASCII-only — существующий гейт.
- dry-run: вывод содержит баннер и строки `legacy=`/`path=`, **не содержит**
  `\u001b` при перенаправленном stdout (тесты всегда pipe).
- legacy npm: `retired legacy npm launcher`, backup-файл, `verified: mma ->`.
- `bash -n scripts/install.sh` и реальный прогон `install-retry` на Windows.

## Откат

Визуальные изменения изолированы функциями `Show-Mascot`/`Draw-Bar`/`banner`/
`draw_bar`; удаление или отключение через `NO_COLOR` не влияет на установку.
