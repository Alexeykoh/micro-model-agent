## Волна 8 — нештатные ситуации в браузере

**Высоко:**

- **Сервер `mma web` умер молча посреди сессии.** Браузер получил
  `ERR_CONNECTION_REFUSED`, процесса нет, `stderr` пуст, записи за сегодня в

  диагностики: причину установить нельзя, пользователь видит только «сайт
  недоступен». Нужен heartbeat/запись причины выхода.
- **Прикрепление картинки молча теряется.** Файл принят (миниатюра `div.thumb`
  с `data:image/png`), запрос ушёл, но модель ответила «Картинки нет — ничего не
  приложено». Причина: DLP вырезает image-части для внешнего провайдера
  (`data-policy/guard.ts:105-108`, `allowImagesToExternal: false` по умолчанию),
  при этом UI не сообщает о вырезании, а бейдж DLP считает только текстовые
  редакции. Пользователь уверен, что картинка ушла. Нужен явный нотис
  «изображение не отправлено: политика DLP».

**Средне:**

- **Перезагрузка страницы посреди хода даёт ложный «idle».** После reload UI
  показывает кнопку «отправить» и никакого прогресса, хотя `/api/state` отдаёт
  `busy: true` и тот же `runningSessionId`. Переподхват случился только через
  ~25 с (тогда появился ● «работает»). В окне между ними повторная отправка
  уйдёт в очередь молча.
- В ленте во время хода соседствуют два статуса: «ход завершён · ok» от прошлого
  хода и живой «✦ пишу · NNNs».

**Низко:**
