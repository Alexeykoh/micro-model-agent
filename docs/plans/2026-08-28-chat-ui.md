# План: Новый Chat UI для MMA

**Цель:** Заменить текущий рендеринг (inline/box) на единый chat-формат с thoughts, иконками инструментов и footer'ом модели.

**Вне скоупа:** Логирование (file-log, session-logger), контекст модели (result.output с hint'ами), MoE/compaction/hallucination вывод.

---

## Формат вывода

```
→ Thought: 0.8s
Пользователь просит рассказать о проекте...

↓ step 2: Настройка структуры
📂 list_dir path="."
  bin/
  CHANGELOG.md
  ...
✓ 7ms  ctx +66

↓ step 2: Настройка структуры
👀 read_file path="README.md"
  lines 1-300 of 359
  # Micro Models Agent
  ...
✓ 6ms  ctx +4890

💻 bash command="bun test"
✓ 1.2s  ctx +0

→ Thought: 0.5s
Отлично, у меня достаточно информации...

Micro Models Agent (MMA) — это harness для...

▣ ollama · qwen3.5-9b · 2.8s
```

### Правила формата

| Элемент | Формат | Описание |
|---------|--------|----------|
| Thought | `→ Thought: Xs` + текст | Стриминг чанками, время показывается в конце |
| Step context | `↓ step N: описание` | Над инструментом, если есть план |
| Tool start | `icon friendlyName args` | Иконка + i18n название + аргументы |
| Tool end | `✓/✗ Xs  ctx ±N` | Только статус, время, дельта контекста |
| Tool output | отступ 2 пробела | Вывод инструмента (сворачивание > 50 строк) |
| Tool error | не показывается | Только ✗ в footer |
| Text | `- ` + текст | Ответ модели, prefix перед первым чанком |
| Footer | `▣ model · provider · Xs` | После завершения агента |
