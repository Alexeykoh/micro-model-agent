# Архив документации

Здесь лежит то, что уже не является действующим контрактом, но нужно для истории:
на эти файлы ссылаются `feature-history.md`, `debt.md`, `CHANGELOG.md` и обсуждения.

## Структура

```
archive/
  specs/<год>/      # завершённые и заменённые спеки
  plans/<год>/      # закрытые планы
  analysis/         # разовые исследования
  reports/          # отчёты о прогонах и тестировании
```

## Правила

- Файл **не удаляется**, а переносится: сохраняется трассируемость решения.
- Дата в имени файла не меняется.
- Ссылки на архив обновляются во всех документах; за этим следит
  `tests/docs-link-check.test.ts`.
- Спека возвращается из архива в `docs/specs/`, только если контракт снова стал
  действующим (например, фичу откатили и переписывают заново).
