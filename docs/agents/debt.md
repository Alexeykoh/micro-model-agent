# Реестр долгов (pay-once)

Единый список **осознанно отложенного**: костыли, временные решения, отложенные правки.
Правило — [AGENTS.md «Правило 9»](../../AGENTS.md). `DEBT(<id>)` в коде/спеке ссылается
на строку ниже; гвард `tests/arch/debt-register.test.ts` не даёт ни пометке, ни записи
осиротеть.

**Долг, которого нет здесь, не существует.** «Оставим на потом» без записи — дефект
процесса, а не экономия. Долг можно отложить **один раз**: когда названный триггер
трогает этот код или волна наступила — долг оплачивается, а не переносится.

Реестр должен оставаться коротким. Растущий реестр — сигнал, что задача нарезана
неправильно (правило 3), а не что «долг нормален».

## Оплачено

- `documents-lockfile-drift` — оплачен **2026-10-16**. Что оплатило: `npm install --package-lock-only` перегенерировал `package-lock.json` (npm 11.6.1, minimal churn: `fast-xml-parser@5.11.2` + `pdfjs-dist@6.4.299` и их транзитивные депы/optional `@napi-rs/canvas`, плюс синхронизация версии корня `0.1.0`→`0.5.0`); оба лока согласованы по документным деп, `package.json` не менялся. Критерий выхода «оба лока согласованы по документным деп» выполнен. Пометка `DEBT(documents-lockfile-drift)` в спеке §4.6 снята.
- `documents-inline-unverified` — оплачен **2026-10-16** (W2). Что оплатило: `scripts/build-documents.ts` теперь пишет `--metafile` и после сборки зовёт `scripts/inline-check.ts::missingInlined`, которая падает (`exit 1`), если документная деп, реально импортируемая `src/**`, отсутствует во входах `dist/main.js`. Критерий выхода был «проверка/тест падает, если деп отсутствует в упакованном `dist/main.js`» — реализован и покрыт `tests/documents/inline-check.test.ts` (юнит на `missingInlined` + скан импортов `src`). Пометка в спеке §4.6 снята.

Активный долг остаётся только в таблице выше; список выше — журнал оплат (в таблицу возвращается лишь при рецидиве).
