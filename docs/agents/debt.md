# Реестр долгов (pay-once)

Единый список **осознанно отложенного**: костыли, временные решения, отложенные правки.
Правило — [AGENTS.md «Правило 9»](../../AGENTS.md). `DEBT(<id>)` в коде/спеке ссылается
на строку ниже; гвард `tests/arch/debt-register.test.ts` не даёт ни пометке, ни записи
осиротеть.

**Долг, которого нет здесь, не существует.** «Оставим на потом» без записи — дефект
процесса, а не экономия. Долг можно отложить **один раз**: когда названный триггер
трогает этот код или волна наступила — долг оплачивается, а не переносится.

Реестр должен оставаться коротким. Растущий реестр — сигнал, что задача нарезана
неправильно (правило 3), а не что «долг нормален».
