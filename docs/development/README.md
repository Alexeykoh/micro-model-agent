# Развитие

Сюда кладётся **рабочая карта того, что дальше**: сравнения с другими harness'ами,
заимствования, приоритеты и триггеры. Это не нормативные контракты и не планы работ.

| Документ | О чём |
| -------- | ----- |
| [harness borrow matrix](./2026-11-19-harness-borrow-matrix.md) | Что позаимствовать у Claude Code, DeepSeek Harness, Qwen Code, Codex и Pi; приоритеты `P1…P3`, оценка стоимости, гейты приёмки |

## Правила категории

1. **[AGENTS.md](../../AGENTS.md) действует полностью:** публичный контракт меняется только
   через [спеку](../specs/README.md), новое архитектурное правило — сразу с гейтом
   из [gates.md](../agents/gates.md).
2. Идея без триггера остаётся здесь; в [debt.md](../agents/debt.md) она попадает только
   когда реально взята в работу (иначе реестр долгов разбухнет).
3. Оценка стоимости — в человеко-днях одного разработчика, знакомого с MMA. Это ориентир,
   а не обязательство и не план релиза.
4. Если идея повторяет уже реализованное, она переезжает в раздел «Не берём» с причиной —
   так карта не превращается в копию [feature-history](../agents/feature-history.md).
