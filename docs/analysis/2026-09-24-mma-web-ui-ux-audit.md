## 2. Проблемы

### 2.1 [CRITICAL] Композер ломается во время хода агента — ✅ ИСПРАВЛЕНО

- **Симптом:** в состоянии `busy` (каждый ход) `.input-area` получает `display:flex; flex-direction:row`:
  селекторы, композер и подсказки выстраиваются в строку, поле ввода сжимается с `1036px` до `~281px`,
  подсказки уезжают вправо. Видно на `shots2/09-busy-layout.png`, `live/03-tool.png`.
- **Причина:** глобальное правило `.busy { display:flex; gap:8px; align-items:baseline }` (`styles.css:331`),
  предназначенное для индикатора «думаю» в ленте, совпадало и с `.input-area.busy`
  (JS вешает класс на контейнер, `app.js:1589`), и с `.send-btn.busy`.
- **Фикс:** селектор сужен до `.msgs .busy` (`styles.css:331`). Замер после рестарта:
  `BUSY → .input-area display:block, w=1036` (было `flex, w=1036` с композером `281px`).
- **Замечание по инструментам:** сервер держит ассеты в памяти (`loadAssets()` один раз при старте),
  поэтому после правки `assets/*` нужен **рестарт `mma web`**. HTTP-кеш тут не при чём
  (`Cache-Control: no-store`). Первый замер «не подтвердил» фикс именно из-за старого процесса.

### 2.2 [HIGH] Мобильная навигация по разделам настроек неюзабельна — открыто

- При ширине ≤640px `.menu-col` превращается в горизонтальный скролл-стрип (`flex row; overflow-x:auto`),
  но `.menu-col .mi` сохраняет `width:100%` (`styles.css:540`, media-query `805–818` его не сбрасывает).
- Замер при 390px: контейнер `390px`, `scrollWidth 3774px`, каждый раздел шириной `370px` → **один раздел
  на экран**, остальные 9 — за горизонтальным скроллом без индикации. Скриншот `shots2/08-mobile-settings.png`.
- **Фикс:** в media-query добавить `.menu-col .mi { width: auto; }`.

### 2.3 [MEDIUM] Нет автокомплита слэш-команд в web — открыто

- Ввод `/` не показывает подсказок команд (в ленте — ничего). Команды приходится помнить; справка только через `/help`.
- В REPL completer есть (`src/cli/completer.ts`), в web-клиенте — нет. Скриншот `shots2/03-slash-open.png`.
- **Рекомендация:** выпадающий список команд по `/` (переиспользовать метаданные из `/help`).

### 2.4 [MEDIUM] Ярлыки тулов не локализованы — открыто

- `app.js:33` — хардкод-карта `LABELS` на английском; `labelOf()` (`app.js:321`) не использует
  существующие ключи `tool.friendly.*` (в i18n их 39, en+ru). В русском интерфейсе строки тулов
  остаются английскими («Running command», «Reading file»). Скриншот `live/03-tool.png`.

### 2.5 [LOW] Сайдбар обрезает id сессии — открыто

- `app.js:1809` `String(h.sessionId).slice(0, 8)` → «ses_muff», тогда как вкладки и список сессий
  показывают полный id. Несогласованность после перехода на полные id.

### 2.6 [LOW] Русская плюрализация — открыто

- `web.action.actions` = «{count} действий» → в ленте «1 действий» вместо «1 действие».

### 2.7 [LOW] Имя вкладки сжато до «Сесси…» — открыто

- Полный id во вкладке занимает место, автоимя «Сессия 2026-09-24» ужимается до «Сесси…» — неинформативно.
  Вариант: не показывать имя, когда оно не влезает, либо укорачивать id вкладки осмысленнее.
