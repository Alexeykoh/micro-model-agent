# Замер порога `contextBudget.admitMaxTokens` (§11)

**Дата:** 2026-11-24 · **Ветка:** `fix/admit-threshold-unmeasured`
**Закрывает:** открытый вопрос §11 в
[спеке out-of-context corpus](../archive/specs/2026/2026-10-14-out-of-context-corpus-design.md)
и долг `admit-threshold-unmeasured`.

## Метод

Порог admission режет вывод тула до дескриптора. Слишком низкий порог спиллит
нормальное чтение, слишком высокий — держит в контексте мусор. §11 требует числа
«по замеру, а не на глаз (зависит от окна и числа тулов)».

Измерены две выборки:

1. **Репрезентативные чтения.** Все `.ts/.tsx/.md/.json` файлы в `src/` и `docs/`
   (1695 файлов) — первые 300 строк каждого, потому что 300 строк — дефолт
   `read_file` (`src/tools/read-file.ts:16`). Токены считаются той же функцией,
   что и в admission — `estimateTokens()` из `src/llm/token-counter.ts`.
2. **Живые прогоны.** 46 `history.jsonl` из `.mma/certification`, 226 записей
   `role: "tool"` (реальные ответы тулов в сертификационных сессиях).

## Результат

| Метрика | 300-строчные окна | Живые tool-ответы |
| ------- | ----------------- | ----------------- |
| Размер выборки | 1695 | 226 |
| p50 | 1096 | 25 |
| p90 | 3012 | 94 |
| p95 | 3620 | 108 |
| max | 31024 | 3754 |
| > 3000 | 173 (10,2%) | 1 (0,4%) |
| > 4000 | 70 (4,1%) | 0 |

## Решение

**Дефолт `admitMaxTokens = 4000`** (был 3000 — placeholder без замера).

- 4000 покрывает p95 обычного 300-строчного чтения (3620) с запасом; доля
  спилленных нормальных чтений падает с 10,2% до 4,1% — остаток это реально
  длинные файлы, для которых дескриптор и задуман.
- Единственный живой ответ выше старого порога (3754) перестаёт спиллиться.
- При дефольном окне 32 768 токенов 4000 — 12,2% окна: один большой вывод не
  вытесняет историю, но и не уходит в мусор целиком.
- Диапазон конфига 200–8000 не меняется; 4000 внутри него.

Число зафиксировано в `DEFAULT_ADMIT_MAX_TOKENS`
(`src/config/defaults.ts`), гвард — `tests/config-admit-tokens.test.ts`.
Повторный замер: та же выборка и та же функция `estimateTokens()`; ключевые
пороги выше приведены в таблице.
