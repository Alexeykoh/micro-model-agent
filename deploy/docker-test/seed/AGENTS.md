# Песочница mma web (docker-стенд)

Ты работаешь внутри тестового контейнера. Рабочая директория — `/workspace`
(на хосте это отдельная папка, не репозиторий mma). Здесь нет исходников mma,
`bun run quality`, `bun test` и гейтов проекта — это не та задача.

## Что доступно

- Сеть и loopback разрешены: `curl http://localhost:<port>` работает, браузер
  (Playwright Chromium) установлен и готов.
- Файлы создавай в `/workspace`, в подкаталогах — сколько нужно.

## Dev-серверы

Сервер обязан слушать `0.0.0.0`, иначе снаружи он не откроется:

```bash
bun run dev -- --host 0.0.0.0
```

Vite 5.4+ проверяет заголовок `Host`; для доступа по внешнему адресу нужен
`server.allowedHosts` в конфиге проекта (для стенда допустимо `true`).

Запускай в фоне и не блокируй сессию:

```bash
nohup bun run dev -- --host 0.0.0.0 >/tmp/dev.log 2>&1 &
```

Проверка — коротким `curl` после readiness-поллинга (не больше ~5 попыток),
затем останавливай сервер по PID.

## Порты, опубликованные наружу

`3000-3010`, `5173-5183`, `8000-8010`, `8081-8090`.

Любой сервис на этих портах доступен снаружи как `http://<host-ip>:<port>`.
Порт `7334` занят панелью mma — не используй его. Другие порты внутри
контейнера работают локально, но снаружи недоступны.
