# F5: Vercel AI SDK

## Findings

### [1] Current version is AI SDK 7.x (package `ai`), with 25.6k GitHub stars and 98.6k dependents
- quote: "AI SDK 7 is now available. Read the announcement"
- url: https://sdk.vercel.ai/docs/introduction
- source_type: primary
- published: 2026
- confidence: high

### [2] Unified provider architecture via language model specification abstracts all providers behind a single API
- quote: "AI SDK Core offers a standardized approach to interacting with LLMs through a language model specification that abstracts differences between providers. This unified interface allows you to switch between providers with ease while using the same API for all providers."
- url: https://sdk.vercel.ai/docs/foundations/providers-and-models
- source_type: primary
- published: unknown
- confidence: high

### [3] Two core text functions: `generateText` (non-streaming) and `streamText` (streaming), both support tools and multi-step loops
- quote: "The AI SDK Core provides two functions to generate text and stream it from LLMs: generateText and streamText. Advanced LLM features such as tool calling and structured data generation are built on top of text generation."
- url: https://sdk.vercel.ai/docs/ai-sdk-core/generating-text
- source_type: primary
- published: unknown
- confidence: high

### [4] Tool calling uses Zod schemas with `tool()` helper, supports multi-step via `stopWhen: isStepCount(N)`, and has strict mode per-tool
- quote: "Tools are objects that can be called by the model to perform a specific task. Function tools and dynamic tools contain several core elements: description, inputSchema (Zod schema or JSON schema), execute (optional async function), and strict (optional boolean)."
- url: https://sdk.vercel.ai/docs/ai-sdk-core/tools-and-tool-calling
- source_type: primary
- published: unknown
- confidence: high

### [5] `ToolLoopAgent` class encapsulates model, tools, instructions into a reusable agent with `generate()` and `stream()` methods
- quote: "The ToolLoopAgent provides a structured way to encapsulate LLM configuration, tools, and behavior into reusable components. It handles the agent loop for you, allowing the LLM to call tools multiple times in sequence to accomplish complex tasks."
- url: https://sdk.vercel.ai/docs/agents/building-agents
- source_type: primary
- published: unknown
- confidence: high

### [6] Ollama is supported via community providers (not official), with two options: `ollama-ai-provider-v2` and `ai-sdk-ollama`
- quote: "The AI SDK supports Ollama through two community providers: nordwestt/ollama-ai-provider-v2 - Direct HTTP API integration; ai-sdk-ollama - Built on the official Ollama JavaScript client."
- url: https://sdk.vercel.ai/providers/community-providers/ollama
- source_type: primary
- published: unknown
- confidence: high

### [7] Official first-party providers: OpenAI, Anthropic, Google, Azure, Amazon Bedrock, Mistral, Together.ai, Groq, DeepSeek, Cerebras (16+ official)
- quote: "The AI SDK comes with a wide range of providers that you can use to interact with different language models: OpenAI, Anthropic, Google, Azure, Amazon Bedrock, Mistral, Together.ai, Cohere, Fireworks, DeepInfra, DeepSeek, Cerebras, Groq, Perplexity, and more."
- url: https://sdk.vercel.ai/docs/foundations/providers-and-models
- source_type: primary
- published: unknown
- confidence: high

### [8] Provider packages follow `@ai-sdk/<name>` naming; Vercel AI Gateway provides unified model string access without per-provider imports
- quote: "By default, the AI SDK uses the Vercel AI Gateway to give you access to all major providers out of the box. Just pass a model string for any supported model: model: 'anthropic/claude-opus-4.6'. You can also connect to providers directly: npm install @ai-sdk/openai @ai-sdk/anthropic @ai-sdk/google"
- url: https://github.com/vercel/ai
- source_type: primary
- published: unknown
- confidence: high

### [9] Streaming supports ReadableStream + AsyncIterable with rich event types: text-delta, tool-call, tool-result, reasoning-delta, finish, error, etc.
- quote: "result.textStream is both a ReadableStream and an AsyncIterable. The stream property yields events: start, text-delta, text-end, reasoning-delta, tool-call, tool-input-delta, tool-result, finish-step, finish, error, raw."
- url: https://sdk.vercel.ai/docs/ai-sdk-core/generating-text
- source_type: primary
- published: unknown
- confidence: high

### [10] Tool approval system supports per-tool `toolApproval` with 'user-approval', 'approved', 'denied', 'not-applicable' states and generic approval functions
- quote: "By default, tools with an execute function run automatically as the model calls them. Configure approval with toolApproval on generateText, streamText, or ToolLoopAgent. toolApproval can be either a GenericToolApprovalFunction or a per-tool map."
- url: https://sdk.vercel.ai/docs/ai-sdk-core/tools-and-tool-calling
- source_type: primary
- published: unknown
- confidence: high

### [11] Loop control via `stopWhen` with composable conditions: `isStepCount(N)`, `hasToolCall(...names)`, `isLoopFinished()`, default 20 steps
- quote: "By default, agents run for 20 steps (stopWhen: isStepCount(20)). You can combine multiple conditions. The loop continues until a finish reasoning other than tool-calls is returned, or a tool without execute is called, or approval is needed, or a stop condition is met."
- url: https://sdk.vercel.ai/docs/agents/building-agents
- source_type: primary
- published: unknown
- confidence: high

### [12] Framework-agnostic UI layer (`@ai-sdk/react`) with `useChat` hook, plus `createAgentUIStreamResponse` for API routes
- quote: "The AI SDK UI module provides a set of hooks that help you build chatbots and generative user interfaces. These hooks are framework agnostic, so they can be used in Next.js, React, Svelte, and Vue."
- url: https://sdk.vercel.ai/docs/introduction
- source_type: primary
- published: unknown
- confidence: high
