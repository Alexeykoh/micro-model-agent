# F2: Claude Code / CLI Coding Agent Patterns

## Findings

### [1] The agentic loop follows a 3-phase cycle: gather context → take action → verify results, repeating until task completion
- quote: "When you give Claude a task, it works through three phases: gather context, take action, and verify results. These phases blend together."
- url: https://code.claude.com/docs/en/how-claude-code-works.md
- source_type: primary
- published: 2026-07
- confidence: high

### [2] Tool definitions use JSON schemas with permission requirements; tools are categorized into file ops, search, execution, web, and code intelligence
- quote: "The built-in tools generally fall into five categories, each representing a different kind of agency: File operations, Search, Execution, Web, Code intelligence."
- url: https://code.claude.com/docs/en/how-claude-code-works.md
- source_type: primary
- published: 2026-07
- confidence: high

### [3] Subagents get their own fresh context windows with custom system prompts and limited tool access, returning only summaries to the parent
- quote: "Each subagent runs in its own context window with a custom system prompt, specific tool access, and independent permissions... returns only the summary."
- url: https://code.claude.com/docs/en/sub-agents.md
- source_type: primary
- published: 2026-07
- confidence: high

### [4] CLAUDE.md files are injected as user messages after the system prompt, not as part of the system prompt itself
- quote: "CLAUDE.md content is delivered as a user message after the system prompt, not as part of the system prompt itself."
- url: https://code.claude.com/docs/en/memory.md
- source_type: primary
- published: 2026-07
- confidence: high

### [5] The SDK agent loop processes turns until Claude produces output with no tool calls; each turn executes tools and feeds results back
- quote: "A turn is one round trip inside the loop: Claude produces output that includes tool calls, the SDK executes those tools, and the results feed back to Claude automatically... Turns continue until Claude produces output with no tool calls."
- url: https://code.claude.com/docs/en/agent-sdk/agent-loop.md
- source_type: primary
- published: 2026-07
- confidence: high

### [6] Context accumulates across turns and is managed via automatic compaction that summarizes older messages while preserving recent exchanges
- quote: "When the context window approaches its limit, the SDK automatically compacts the conversation: it summarizes older history to free space, keeping your most recent exchanges and key decisions intact."
- url: https://code.claude.com/docs/en/agent-sdk/agent-loop.md
- source_type: primary
- published: 2026-07
- confidence: high

### [7] Persistent content (system prompt, tool definitions, CLAUDE.md) is automatically prompt-cached to reduce cost on repeated requests
- quote: "Content that stays the same across turns (system prompt, tool definitions, CLAUDE.md) is automatically prompt cached, which reduces cost and latency for repeated prefixes."
- url: https://code.claude.com/docs/en/agent-sdk/agent-loop.md
- source_type: primary
- published: 2026-07
- confidence: high

### [8] Skills are loaded on-demand: descriptions are always in context but full content only loads when invoked, keeping context lean
- quote: "Claude sees skill descriptions at session start, but the full content only loads when a skill is used."
- url: https://code.claude.com/docs/en/how-claude-code-works.md
- source_type: primary
- published: 2026-07
- confidence: high

### [9] Hooks intercept tool calls at lifecycle events (PreToolUse, PostToolUse) without consuming context, enabling validation and side effects
- quote: "Hooks are callbacks that fire at specific points in the loop: before a tool runs, after it returns, when the agent finishes... Hooks run in your application process, not inside the agent's context window, so they don't consume context."
- url: https://code.claude.com/docs/en/agent-sdk/agent-loop.md
- source_type: primary
- published: 2026-07
- confidence: high

### [10] Aider uses a "repo map" pattern that generates a compact repository structure overview to give the LLM codebase awareness without reading all files
- quote: "If use_repo_map and self.repo and has_map_prompt: self.repo_map = RepoMap(map_tokens, self.root, self.main_model, io, self.gpt_prompts.repo_content_prefix, self.verbose, max_inp_tokens, map_mul_no_files=map_mul_no_files, refresh=map_refresh)"
- url: https://github.com/Aider-AI/aider/blob/main/aider/coders/base_coder.py
- source_type: primary
- published: 2026-07
- confidence: high

### [11] Aider compresses chat history via a summarizer when context gets too big, moving messages from cur_messages to done_messages and summarizing
- quote: "self.summarizer = summarizer or ChatSummary([self.main_model.weak_model, self.main_model], self.main_model.max_chat_history_tokens)"
- url: https://github.com/Aider-AI/aider/blob/main/aider/coders/base_coder.py
- source_type: primary
- published: 2026-07
- confidence: high

### [12] Permission modes gate tool execution with escalating autonomy: manual → acceptEdits → plan → auto → dontAsk → bypassPermissions
- quote: "Press Shift+Tab to cycle through permission modes: Manual, Accept edits, Plan, Auto"
- url: https://code.claude.com/docs/en/how-claude-code-works.md
- source_type: primary
- published: 2026-07
- confidence: high

### [13] MCP tool schemas can be deferred (names only in context) and loaded on-demand via tool search, preventing hundreds of tools from consuming context upfront
- quote: "MCP tool schemas deferred by default; only tool names consume context until Claude uses a specific tool"
- url: https://code.claude.com/docs/en/context-window.md
- source_type: primary
- published: 2026-07
- confidence: high

### [14] The agent loop supports configurable limits: max_turns, max_budget_usd, and effort level (low/medium/high/xhigh/max) to trade reasoning depth for cost
- quote: "Max turns (max_turns / maxTurns): Maximum tool-use round trips... Effort level controls how much reasoning Claude applies. Lower effort levels use fewer tokens per turn."
- url: https://code.claude.com/docs/en/agent-sdk/agent-loop.md
- source_type: primary
- published: 2026-07
- confidence: high
