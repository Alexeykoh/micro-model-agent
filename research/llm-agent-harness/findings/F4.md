# F4: AGENTS.md / Skills Patterns

## Findings

### [1] AGENTS.md is an open standard for guiding coding agents, placed in project root as a simple markdown file
- quote: "AGENTS.md is a simple, open format for guiding coding agents. Think of AGENTS.md as a README for agents: a dedicated, predictable place to provide context and instructions."
- url: https://github.com/agentsmd/agents.md
- source_type: primary
- published: 2026
- confidence: high

### [2] Cursor uses .mdc rule files with frontmatter metadata controlling activation (always, glob-match, description-match, or manual @-mention)
- quote: "Each rule is a markdown file with frontmatter metadata and content. Control how rules are applied from the type dropdown which changes properties description, globs, alwaysApply."
- url: https://cursor.com/docs/context/rules
- source_type: primary
- published: 2026
- confidence: high

### [3] Cursor supports nested AGENTS.md files in subdirectories with more-specific instructions taking precedence
- quote: "Nested AGENTS.md support in subdirectories is now available. Instructions from nested AGENTS.md files are combined with parent directories, with more specific instructions taking precedence."
- url: https://cursor.com/docs/context/rules
- source_type: primary
- published: 2026
- confidence: high

### [4] Microsoft Skills repo has 175+ SKILL.md files organized by language plugins with YAML frontmatter (name, description, triggers)
- quote: "Skills, custom agents, AGENTS.md templates, and MCP configurations for AI coding agents working with Azure SDKs and Microsoft AI Foundry."
- url: https://github.com/microsoft/skills
- source_type: primary
- published: 2026
- confidence: high

### [5] Claude Code plugins follow a standard structure: plugin.json metadata, commands/, agents/, skills/, hooks/ directories
- quote: "Each plugin follows the standard Claude Code plugin structure: .claude-plugin/plugin.json, commands/, agents/, skills/, hooks/, .mcp.json"
- url: https://github.com/anthropics/claude-code/blob/main/plugins/README.md
- source_type: primary
- published: 2026
- confidence: high

### [6] OpenCode uses custom commands as Markdown files with named argument placeholders ($NAME syntax)
- quote: "Custom commands are predefined prompts stored as Markdown files in one of three locations: User Commands, Project Commands."
- url: https://github.com/opencode-ai/opencode
- source_type: primary
- published: 2025
- confidence: high

### [7] Skills in Microsoft's system use SKILL.md files that become additional instructions for the scope of that invocation
- quote: "A skill's body becomes additional instructions for the scope of that invocation; treat it as authoritative."
- url: https://github.com/microsoft/skills
- source_type: primary
- published: 2026
- confidence: high

### [8] Cursor distinguishes four rule types: Always Apply, Apply Intelligently (by description), Apply to Specific Files (by glob), and Apply Manually (@-mention)
- quote: "Cursor supports four types of rules: Project Rules, User Rules, Team Rules, AGENTS.md."
- url: https://cursor.com/docs/context/rules
- source_type: primary
- published: 2026
- confidence: high

### [9] Microsoft Skills installs via npx skills add with symlink support for multi-agent sharing
- quote: "npx skills add microsoft/skills. Skills are installed to your chosen agent's directory and symlinked if you use multiple agents."
- url: https://github.com/microsoft/skills
- source_type: primary
- published: 2026
- confidence: high

### [10] Plugin system includes hooks (PreToolUse, SessionStart) for intercepting agent behavior at lifecycle events
- quote: "Hook: SessionStart - Injects educational context at the start of each session. Hook: PreToolUse - Monitors 9 security patterns."
- url: https://github.com/anthropics/claude-code/blob/main/plugins/README.md
- source_type: primary
- published: 2026
- confidence: high

### [11] Team Rules in Cursor can be enforced org-wide from dashboard, taking precedence over project and user rules
- quote: "Rules are applied in this order: Team Rules → Project Rules → User Rules. All applicable rules are merged; earlier sources take precedence when guidance conflicts."
- url: https://cursor.com/docs/context/rules
- source_type: primary
- published: 2026
- confidence: high

### [12] Microsoft categorizes skills with symlinks into language/category folders (foundry, data, messaging, monitoring, entra, integration, compute, m365, general)
- quote: "Categorize with symlink in skills/<language>/<category>/. Categories: foundry, data, messaging, monitoring, entra, integration, compute, m365, general."
- url: https://github.com/microsoft/skills
- source_type: primary
- published: 2026
- confidence: high
