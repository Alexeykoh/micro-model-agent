# Research Brief: Bash-First LLM Agents

**Date:** 2026-07-16
**Depth:** deep
**Audience:** Engineer building a bash-first agent for 9B parameter models

## Question
How should a "bash-first" LLM agent be structured — one that uses shell/bash as its primary tool interface — targeting small (9B) models? What are the concrete patterns, safety mechanisms, and architectural decisions from existing implementations (Claude Code, OpenCode, etc.)?

## Scope
- IN: Agent architecture, tool design patterns, bash safety, small model techniques, agentic loop design
- OUT: Fine-tuning recipes, model training, specific model comparisons beyond 9B class
- Time frame: 2024-2026 (modern agent frameworks)

## Angles
1. Claude Code's bash tool architecture
2. OpenCode's tool system
3. Bash as universal interface for small models
4. Safety patterns for bash execution
5. Context-efficient tool design for small models
6. Agentic loops and prompt patterns
7. Working with 9B models
