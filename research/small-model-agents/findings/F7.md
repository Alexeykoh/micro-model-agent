# F7: Qwen-Specific Tips for Agent Performance

## Findings

### [1] Qwen2.5 tool calling uses Hermes-inspired template format; vLLM requires `--tool-call-parser hermes` flag
- quote: "The vllm / Ollama / transformers tool calling support uses a tool calling template inspired by Nous' Hermes."
- url: https://qwenlm.github.io/blog/qwen2.5/
- source_type: primary
- published: 2024-09-19
- confidence: high

### [2] Qwen2.5-7B specifically improved structured JSON output generation and is more resilient to diverse system prompts
- quote: "Significant improvements in instruction following, generating long texts (over 8K tokens), understanding structured data (e.g, tables), and generating structured outputs especially JSON. More resilient to the diversity of system prompts."
- url: https://huggingface.co/Qwen/Qwen2.5-7B-Instruct
- source_type: primary
- published: September 2024
- confidence: high

### [3] Qwen3 supports thinking/non-thinking mode switching via `enable_thinking=False` parameter or `/think` and `/no_think` instructions in messages
- quote: "By default, Qwen3 models will think before response. This could be controlled by enable_thinking=False: Passing enable_thinking=False to tokenizer.apply_chat_template will strictly prevent the model from generating thinking content."
- url: https://github.com/QwenLM/Qwen3/blob/main/README.md
- source_type: primary
- published: 2025-04-29
- confidence: high

### [4] SGLang and vLLM preprocessing drops `reasoning_content` fields, making multi-step tool use with Qwen3 thinking models suboptimal — workaround: pass content as-is
- quote: "the quality of multi-step tool use with Qwen3 thinking models may be suboptimal, which requires the existence of the related thinking content. While the fixes are being worked on, as a workdaround, we recommend passing the content as it is, without extracting thinking content"
- url: https://github.com/QwenLM/Qwen3/blob/main/README.md
- source_type: primary
- published: 2025-04-29
- confidence: high

### [5] Qwen3-2507 (July 2025) introduces separate Instruct and Thinking variants with 256K context, extending to 1M tokens
- quote: "Qwen3-Instruct-2507 is the updated version of the previous Qwen3 non-thinking mode, featuring the following key enhancements: Significant improvements in general capabilities, including instruction following, logical reasoning, text comprehension, mathematics, science, coding and tool usage."
- url: https://github.com/QwenLM/Qwen3/blob/main/README.md
- source_type: primary
- published: 2025-07-21
- confidence: high

### [6] Qwen2.5-7B default config supports 32,768 tokens; YaRN scaling enables 128K but vLLM only supports static YARN (may impact short text performance)
- quote: "The current config.json is set for context length up to 32,768 tokens. To handle extensive inputs exceeding 32,768 tokens, we utilize YaRN... Presently, vLLM only supports static YARN, which means the scaling factor remains constant regardless of input length, potentially impacting performance on shorter texts."
- url: https://huggingface.co/Qwen/Qwen2.5-7B-Instruct
- source_type: primary
- published: September 2024
- confidence: high

### [7] Ollama defaults to 2K context and infinite generation — requires explicit `num_ctx` and `num_predict` configuration for Qwen models
- quote: "Ollama adopts the same 'rotating context management' with llama.cpp. However, its default settings (num_ctx 2048 and num_predict -1), suggesting infinite generation with a 2048-token context, could lead to trouble for Qwen3 models. We recommend setting num_ctx and num_predict properly."
- url: https://github.com/QwenLM/Qwen3/blob/main/README.md
- source_type: primary
- published: 2025-04-29
- confidence: high

### [8] Qwen-Agent is the official recommended framework for tool use with Qwen models, providing MCP support
- quote: "For tool use capabilities, we recommend taking a look at Qwen-Agent, which provides a wrapper around these APIs to support tool use or function calling with MCP support."
- url: https://github.com/QwenLM/Qwen3/blob/main/README.md
- source_type: primary
- published: 2025-04-29
- confidence: high

### [9] Qwen2.5-7B-Instruct has 7.61B parameters with 28 layers, GQA (28 Q heads, 4 KV heads), supporting full 131K context
- quote: "Number of Parameters: 7.61B, Number of Paramaters (Non-Embedding): 6.53B, Number of Layers: 28, Number of Attention Heads (GQA): 28 for Q and 4 for KV, Context Length: Full 131,072 tokens and generation 8192 tokens"
- url: https://huggingface.co/Qwen/Qwen2.5-7B-Instruct
- source_type: primary
- published: September 2024
- confidence: high

### [10] llama.cpp requires `--jinja` flag for Qwen3 function calling templates; recommended version is b5401+
- quote: "llama.cpp>=b5401 is recommended for the full support of Qwen3."
- url: https://github.com/QwenLM/Qwen3/blob/main/README.md
- source_type: primary
- published: 2025-04-29
- confidence: high

### [11] Qwen2.5-Coder-7B trained on 5.5 trillion tokens of code data, competitive against larger general models on coding benchmarks
- quote: "Qwen2.5-Coder has been trained on 5.5 trillion tokens of code-related data, enabling even smaller coding-specific models to deliver competitive performance against larger language models on coding evaluation benchmarks."
- url: https://qwenlm.github.io/blog/qwen2.5/
- source_type: primary
- published: 2024-09-19
- confidence: high
