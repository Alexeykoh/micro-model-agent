# F6: Open-Source Coding Agents for Small Models

## Findings

### [1] smolagents (HuggingFace) explicitly supports local transformers models and Ollama for small model inference, with a code-agent paradigm that uses 30% fewer LLM calls than JSON tool-calling
- quote: "CodeAgent works mostly like classical ReAct agents — the exception being that the LLM engine writes its actions as Python code snippets... Writing actions as code snippets is demonstrated to work better than the current industry practice of letting the LLM output a dictionary of the tools it wants to call: uses 30% fewer steps"
- url: https://github.com/huggingface/smolagents
- source_type: primary
- published: unknown (repo current as of v1.26.0, May 29 2026)
- confidence: high

### [2] smolagents benchmarks show open-source models (DeepSeek-R1) beating closed-source models on agentic workflows, validating small-model viability
- quote: "This comparison shows that open-source models can now take on the best closed models!"
- url: https://github.com/huggingface/smolagents
- source_type: primary
- published: unknown
- confidence: medium (no specific 7B-9B results shown in README; benchmark image not readable as text)

### [3] Aider explicitly warns that models weaker than GPT-3.5 struggle with its code-editing format, and provides Ollama integration with configurable context windows for local models
- quote: "Be aware that aider may not work well with less capable models. If you see the model returning code, but aider isn't able to edit your files and commit the changes… this is usually because the model isn't capable of properly returning 'code edits'. Models weaker than GPT 3.5 may have problems working well with aider."
- url: https://aider.chat/docs/llms.html
- source_type: primary
- published: unknown
- confidence: high

### [4] Aider's Ollama integration defaults to 2K context window (dangerously small for agent use) and silently discards excess context — requires explicit configuration to 8K+ tokens for reliable operation
- quote: "Ollama uses a 2k context window by default, which is very small for working with aider. It also silently discards context that exceeds the window. This is especially dangerous because many users don't even realize that most of their data is being discarded by Ollama."
- url: https://aider.chat/docs/llms/ollama.html
- source_type: primary
- published: unknown
- confidence: high

### [5] Open Interpreter has rebranded as "a coding agent optimized for low-cost models" and ships with harness emulation for multiple small-model-friendly presets including qwen-code, deepseek-tui, and kimi-cli
- quote: "Open Interpreter is a fork of OpenAI's Codex, with a focus on emulating the agent harness that gets the best performance out of low-cost models."
- url: https://github.com/openinterpreter/openinterpreter
- source_type: primary
- published: unknown (Rust rewrite, latest release v0.0.25 Jul 15 2026)
- confidence: high

### [6] Open Interpreter's harness system includes pre-built prompt/harness templates for Qwen, DeepSeek, and Kimi — directly relevant to small-model deployment patterns
- quote: "Use `/harness` to switch the active harness: native, claude-code, claude-code-bare, zcode, kimi-cli, qwen-code, deepseek-tui, swe-agent, minimal"
- url: https://github.com/openinterpreter/openinterpreter
- source_type: primary
- published: unknown
- confidence: high

### [7] Cline supports Ollama and LM Studio for local model execution, plus any OpenAI-compatible API — positioning it as model-agnostic with 64.7k stars indicating strong community adoption
- quote: "Cline is not locked to a single AI provider. Use whichever model fits your workflow... Ollama / LM Studio: Run local models on your machine"
- url: https://github.com/cline/cline
- source_type: primary
- published: unknown (CLI v3.0.42 Jul 16 2026)
- confidence: high

### [8] Continue.dev has been archived (read-only) as of June 2026 after a final 2.0.0 release — the repository is no longer actively maintained
- quote: "Note: The continuedev/continue repository is no longer actively maintained and is read-only for all users."
- url: https://github.com/continuedev/continue
- source_type: primary
- published: Jun 19 2026 (final release)
- confidence: high

### [9] Roo Code was shut down on May 15, 2026 — community forked to ZooCode, making it unreliable as a long-term small-model coding agent platform
- quote: "The Roo Code Extension was shut down on May 15th. If you're looking for an alternative, check out ZooCode (a fork started by the Roo Code community)"
- url: https://github.com/RooCodeInc/Roo-Code
- source_type: primary
- published: May 15 2026
- confidence: high

### [10] OpenHands has pivoted to a "developer control center" architecture (Agent Canvas) that supports any ACP-compatible agent, with "Bring your own model" for any LLM including local inference
- quote: "Bring your own model — Use with any LLM"
- url: https://github.com/OpenHands/OpenHands
- source_type: primary
- published: unknown (cloud 1.46.2 Jul 15 2026)
- confidence: medium (no specific small-model benchmarks or adaptations documented in README)

### [11] The code-agent paradigm (writing actions as code rather than JSON tool calls) is the most promising adaptation for small models — smolagents' research shows it reduces steps by 30% and improves benchmark performance
- quote: "Writing actions as code snippets is demonstrated to work better than the current industry practice... uses 30% fewer steps (thus 30% fewer LLM calls) and reaches higher performance on difficult benchmarks"
- url: https://github.com/huggingface/smolagents
- source_type: primary
- published: unknown (references papers from 2024)
- confidence: high

### [12] Open Interpreter's architecture is specifically designed around harness emulation — different prompt/system-prompt configurations per model family to extract maximum performance from lower-capability models
- quote: "a coding agent optimized for low-cost models"
- url: https://github.com/openinterpreter/openinterpreter
- source_type: primary
- published: unknown
- confidence: high
